# CLIESC_EUREKA_RESTFUL_JAVA — Cliente de Escritorio (Swing)

Consume el servidor `WS_EUREKA_RESTFUL_JAVA`. Java 21 + Swing con tema oscuro FlatLaf.
MVC: `modelo` (ServicioRest, Json, DTOs), `vista` (VentanaLogin, VentanaPrincipal, Estilo, Componentes), `controlador` (ControladorEscritorio).

## Ejecutar
- NetBeans: clic derecho en el proyecto → Run.
- Ejecutable: Clean and Build → doble clic en `ejecutar_escritorio.bat` (o `target\CLIESC_EUREKA_RESTFUL_JAVA.jar`).

## Imagen del Monster
Copiar la imagen como `src/main/resources/img/monster.png` y volver a ejecutar.
