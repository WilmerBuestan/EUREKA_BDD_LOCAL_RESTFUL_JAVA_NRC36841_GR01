# CLICON_EUREKA_RESTFUL_JAVA — Cliente de Consola

Consume el servidor `WS_EUREKA_RESTFUL_JAVA`. Java 21, sin librerías externas. MVC: `modelo` (ServicioRest, Json, DTOs), `vista` (VistaConsola), `controlador` (ControladorConsola).

## Ejecutar
- NetBeans: clic derecho → Run (la consola aparece en la pestaña Output).
- Con colores: clic derecho → Clean and Build, luego doble clic en `ejecutar_consola.bat`.
- Otro servidor: `ejecutar_consola.bat http://192.168.1.10:8080/WS_EUREKA_RESTFUL_JAVA/api`
- Sin colores: agregar `--sin-color`.
